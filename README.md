# 💫 About Me:
I’m Darshit Thakkar, a BSc-IT graduate from Harivandana College, with a strong passion for MERN Stack Development, Data Science, and Python Programming. I have hands-on experience building full-stack web applications using React, Node.js, Express, and MongoDB, along with a solid foundation in data analysis using Python, Pandas, Power BI, and basic machine learning. I’m driven by a curiosity to learn and a goal to grow as a well-rounded tech professional blending development and data.
